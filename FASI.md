# Fasi di valutazione

Il documento di valutazione delle fasi è del committente e vive fuori da
questo repository: qui non ne viene ricostruito né riassunto il contenuto.
Di quel processo questo file riporta soltanto ciò che i prompt di
correzione dichiarano, e tiene il registro degli esiti delle iterazioni
di correzione. Se il committente consegnerà l'originale, questo file sarà
sostituito conservando il registro.
